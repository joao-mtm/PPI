Especificidade no CSS

A especificidade define qual regra CSS será aplicada quando existem várias regras para o mesmo elemento.

Exemplo:

  • Abacaxi
  • Maçã
  • Uva

Explicação

A regra li deixa todos os itens vermelhos.

A regra .fruta é mais específica, então a maçã fica cinza.

A regra #uva é mais específica que .fruta, então a uva fica azul.

A regra #uva.fruta é ainda mais específica, então a uva fica laranja.

Observação: Essa especificidade segue o mesmo molde para todos os elementos do exemplo aqui dei apenas um exemplo mas serve para todos

Resultado

    Abacaxi → vermelho
    Maçã → cinza
    Uva → laranja
