Internet e Web

A Internet é uma grande rede mundial que conecta computadores, celulares e outros dispositivos. Ela permite a comunicação e a troca de dados entre diferentes redes ao redor do mundo. A Web é um serviço que funciona dentro da Internet e permite acessar sites e páginas.

História da Internet e da Web

A história da Internet começou durante a década de 1960, quando pesquisadores buscavam maneiras de conectar computadores e compartilhar informações.

Em 1969, surgiu a ARPANET, uma rede criada nos Estados Unidos que é considerada um dos principais antecessores da Internet moderna. Durante as décadas seguintes, novas tecnologias e protocolos foram desenvolvidos. Um dos principais acontecimentos foi a criação do protocolo TCP/IP, adotado pela ARPANET em 1983

Principais marcos

  1. 1969: criação da ARPANET.
  2. 1971: envio de um dos primeiros e-mails.
  3. 1983: adoção do TCP/IP pela ARPANET.
  4. 1989: Tim Berners-Lee propõe a World Wide Web.
  5. 1991: a Web é disponibilizada publicamente.
  6. 1993: o navegador Mosaic ajuda a popularizar a Web.
  7. 1995: a Internet comercial cresce rapidamente.
  8. 2000 em diante: expansão das redes sociais, serviços de streaming,smartphones e computação em nuvem.

Diferenças entre Internet e Web
Internet Web
É uma rede mundial de computadores e dispositivos. É um sistema de páginas e recursos acessados pela Internet.
Utiliza protocolos como TCP/IP. Utiliza tecnologias como HTML, HTTP e URLs.

Internet e Web são relacionadas, mas representam conceitos diferentes.

O nascimento da World Wide Web

Em 1989, o cientista britânico Tim Berners-Lee, trabalhando no CERN, apresentou uma proposta para facilitar o compartilhamento de informações entre pesquisadores.

Essa proposta deu origem à World Wide Web.A primeira página Web foi colocada no ar em 1991. A Web utilizava conceitos fundamentais comoHTML, HTTP e URL. O protocolo TCP/IP utiliza a versão 4 e também a versão6. A Web continua evoluindo até hoje.

A Web transformou a maneira como as pessoas criam, encontram e compartilham informações.

Definições

Internet
Rede mundial que conecta computadores e outros dispositivos.
Web
Sistema de documentos e recursos interligados acessados pela Internet.
HTML
Linguagem de marcação utilizada para estruturar páginas Web.
URL
Endereço utilizado para localizar um recurso na Web.
