HTTP

O HTTP (Hypertext Transfer Protocol) é um protocolo de comunicação utilizado na Web para a transferência de dados entre clientes e servidores. Ele define como as mensagens são formatadas e transmitidas, permitindo que os navegadores solicitem recursos e recebam respostas dos servidores.

Como funciona o HTTP

Quando um usuário acessa um site, o navegador envia uma requisição HTTP ao servidor, solicitando o recurso desejado (como uma página HTML, imagem ou vídeo). O servidor processa a requisição e envia uma resposta HTTP de volta ao navegador, contendo o recurso solicitado ou uma mensagem de erro.

O HTTP é um protocolo sem estado, o que significa que cada requisição é independente e não mantém informações sobre requisições anteriores. Para gerenciar sessões e manter informações entre requisições, são utilizados cookies e outros mecanismos.

Métodos HTTP

  • GET: solicita um recurso do servidor.
  • POST: envia dados para o servidor para criar ou atualizar um recurso.
  • PUT: atualiza um recurso existente no servidor.
  • DELETE: remove um recurso do servidor.
  • HEAD: solicita apenas os cabeçalhos da resposta, sem o corpo.
  • OPTIONS: solicita informações sobre os métodos suportados pelo servidor.

Detalhes de um campo de Request:


  • :method: Mostra qual método HTTP foi utilizado na requisição. No exemplo da imagem retirada do Google Docs, o método utilizado é GET.
  • :authority: Identifica o servidor ou domínio para o qual a requisição está sendo enviada.
  • :path: Mostra o endereço ou caminho do recurso que está sendo solicitado ao servidor.
  • :scheme: Informa qual protocolo está sendo utilizado na comunicação. No exemplo, o protocolo é HTTP.
  • Accept: Especifica quais formatos de conteúdo o navegador está preparado para receber do servidor.
  • Accept-Language: Informa quais idiomas são preferidos pelo navegador para receber o conteúdo.

Detalhes de um campo de Response:


  • Alt-Svc: Indica que o servidor disponibiliza outros protocolos ou formas alternativas de conexão.
  • Cache-Control: Determina como e por quanto tempo o conteúdo pode ser armazenado no cache do navegador.
  • Content-Encoding: Informa qual método de compressão foi utilizado para reduzir o tamanho do conteúdo. Neste caso, foi utilizado gzip.
  • Content-Security-Policy: Estabelece regras de segurança que controlam quais recursos podem ser carregados e executados na página.
